Modeling a 3 qubit Linear Optical Quantum Computer to identify and optimize sources of noise

Problem: Georgia Tech Quantum Computing Association began a new project in assembling a linear optical quantum computer on our own. Our goal is to make the most efficient system possible using the limited optical components we have access to given our budget, which means trying to figure out a way to identify potential sources of optical noise that might result from component configurations.


How I solved the problem:

  • Spent a month getting ridiculously familiarized with the Polarizing Beam Splitter (application ID: 31041) from COMSOL model library
  • Self-studied the Electric Waves, Beam Envelopes method for COMSOL for wave optics
  • Used existing framework of manually calculating phase continuity expressions in order to extend beam propagation out of the PBS and into more domains to model larger setups involving multiple components

Relevant Skills, Concepts, Tools:

  • Finite Element Analysis tool: COMSOL Multiphysics
  • Package: Electromagnetic Waves, Beam Envelopes
  • Concepts: Phase matching expressions, Antireflection coating transition boundaries

Final Products:

  • Abstract accepted to COMSOL 2026 Boston Conference, paper on the way!
  • Georgia Tech Student Foundation Funding Proposal (accepted for $10,000)
  • Detailed Write-up on the process of working on this project

First Author Quantum Machine Learning paper for Time Series Forecasting

Problem: Analyzing advantages/disadvantages of using Quantum Machine Learning in wind turbine degradation forecasting


How I solved the problem:

  • Architected a model that uses a Quantum Long Short Term memory (QLSTM) as the Generator and classical Convolutional Neural Network as discriminator within a Generative Adversarial Network (GAN)
  • Implemented Quantum GAN to forecast turbine’s vibration signals, converging in 2.7x less epochs (49 classical epochs, 18 quantum) with only 169 QLSTM parameters VS 8,186,113 classical LSTM parameters
  • Deployed repository to a High Performance Computing cluster using SLURM to parameterize train/test split across 5 values and repeat each split 10 times to quantify variance in each model’s RMSE performance

Relevant Skills, Concepts, Tools:

  • Programming Language: Python
  • Libraries: Pytorch, Pennylane, Pandas
  • HPC Integration: SLURM for UCSC's Hummingbird cluster
  • Lessons learned: How to write and publish research, Parameterized Quantum Circuits replacing ML layers, Bayesian Optimization for Hyperparameter tuning

Final Products:

  • Conference paper at ESREL'24
  • Revised paper with HPC integration
  • Github repo with 15 stars and 5 forks

Third Author Electric Field distribution simulation and analysis using COMSOL

Problem: Electric Field distribution simulation and analysis using COMSOL


How I solved the problem:

  • Spent a month going through a former PhD student in the lab's 200 page dissertation from 2014 to see how they previously modeled nanopores in comsolSpent a month going through a former PhD student in the lab's 200 page dissertation from 2014 to see how they previously modeled nanopores in comsol
  • Spent one more month converting his approach in COMSOL version 3.5 to COMSOL version 6.2
  • Automated parameter sweep to vary the amount of nanopores (1,2,4,8,10) and distance between nanopores (100 nanometers to 6 micrometers in 100 nm increments) to calculate capture radius for each configuration
  • Eliminated out of memory errors by creating custom mesh with varying element sizes depending on proximity to regions of interest and editing COMSOL’s internal files to increase access to RAM
  • Exported raw electric field distribution data from COMSOL to MATLAB to find an equation to express particle capture radius as a logistic function of nanopore count and placement

Relevant Skills, Concepts, Tools:

  • Finite Element Analysis tool: COMSOL Multiphysics
  • Data analysis: MATLAB, Desmos logistic regression
  • Lessons learned: How to rigorously parse through outdated PhD disserations, AC/DC package for COMSOL, memory optimization

Final Products:

  • Third Author publication on the way!
  • Lab group update presentations
